# Saung Thazin – Money Transfer Agent App

A mobile app that helps money transfer agents record transfers across Myanmar banks and mobile wallets, track customer credit, and see daily, monthly, and yearly profit.

## Features
- Record transfers for KBZPay, Wave, AYA Pay, CB Pay, and other banks and wallets
- Customer management and balance updates
- Credit tracking and payment records
- Daily, monthly, and yearly profit reports
- Date filter for viewing past records

## Tech Stack
React Native 0.70, Firebase Firestore, Firebase Storage, React Navigation

## Getting Started
1. Clone the repo and run `npm install`
2. Add your own `google-services.json` to `android/app/`
3. Run `npx react-native run-android`
